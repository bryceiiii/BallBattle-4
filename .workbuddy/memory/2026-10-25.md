## 复活无敌动画需求调研

- 已产出 `handoff-20261025-invincible-fx.md`：现状表 + 4 方案（A 呼吸闪烁 / B 复用护盾特效 / C 独立光环 / D 进度环）+ 推荐 C+A 兜底 + 5 项格式交接块。

## 修复：小球进入大球时大球应覆盖小球（渲染排序）
- 根因：`Circle.prefab` 球体 `SpriteRenderer.sortingOrder` 恒为 1，所有球同值 → 同值下渲染顺序由提交/批次决定，小球会盖住大球。
- 修复（unityMCP 改 prefab + 改脚本）：
  - `CircleController.cs`：新增 `ballSortingBase=1` / `ballSortingMax=60`、`_appliedSortingOrder` 缓存，`Update()` 缩放平滑后调 `UpdateSortingOrder()`：`order = Clamp(1 + FloorToInt(localScale.x), 1, 60)`，直径越大越靠上。只在值变化时写。
  - 层级整体重排（避免大球盖住特效/UI）：
    Food/特殊食物 0 < 球体 1~60（动态）< 粒子/飘字 100 < 子弹 110 < 护盾 150 < 无敌 160 < 瞄准箭头 170 < 枪口闪光 190 < 名字 Canvas 200 < HP Canvas 201。
  - prefab 改动：`Circle.prefab` Canvas 2→200、HpCanvas 0→201；`ShieldBuff.prefab` 2→150；`Bullet.prefab`/`SpiltBullet.prefab` 0→110；`RespawnInvincibleFx.prefab` 20→160；`FireEffect.prefab` 0→190。
  - 脚本改动：`InvincibleVisual.sortingOrder` 20→160（运行时 AddComponent，默认值即生效）；`AimIndicator` 运行时创建的 AimArrow SpriteRenderer 补 `sortingOrder = 170`。
- 注意：`Circle.prefab` 上的 `Capsule` 为 inactive，未处理。合并动画分支 `Update` 有 early return，期间不刷新排序（不影响，缩小中的小球本就该被大球盖住）。
