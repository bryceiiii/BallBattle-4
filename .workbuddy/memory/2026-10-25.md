## 修复：激光射击方向不对（光柱垂直于射线）
- 现象：激光（bullet_type=2）射出的光柱方向与瞄准方向不一致。
- 定位（unityMCP 实测）：场景 `PrefabsManager.laserBeamPrefab` / `laserHitSparkPrefab` 均为 **NULL** → 走 `LaserBeamFX` 代码兜底生成路径。兜底 `CreateBar` 把 `localScale` 写成 `(width, length, 1)`，而 `rot`（Euler Z = Atan2(dir)）已把 **+X 轴对齐射线方向** → 长度被拉到 Y 轴，光柱垂直于射线。
  实测证据：`Spawn((0,0),(10,0))` 生成的 Core worldBounds = `(0.12, 10)`（宽 0.12、高 10）。
- 修复：`Client-unity/Assets/Scripts/LaserBeamFX.cs`
  - `CreateBar`：`localScale = (length, width, 1)`，注释写明 rot 语义；
  - `CreateBar`/`CreateSpot` 改用 `localPosition = transform.InverseTransformPoint(...)` + `localRotation = Inverse(parentRot) * rot`，不再依赖父物体必须是 identity；
  - prefab 分支拉伸轴同步改为 `s.x * length`（美术预制体需按 1 世界单位、沿 +X 设计）。
- 验证：水平射线 bounds `(10, 0.6)` ✓；45° 射线 localScale `(10,0.12)` + rotZ 45°，bounds `(7.15,7.15)` ✓；Unity Console 0 error / 0 warning。
- 纯客户端表现层，**不需要 publish / generate**。服务端 `FireLaser` 的方向来源（客户端归一化方向）本来就是对的，未改动。

## 修复：Android 打包失败（Burst AOT UnauthorizedAccessException）
- 报错：`Library/Bee/artifacts/Android/AsyncPluginsFromLinker: Burst internal compiler error: System.UnauthorizedAccessException`（+ `BuildFailedException: Burst compiler (1.8.21) failed running`）。
- 调用栈关键点（`Editor.log`，中文消息被双重编码成乱码，可从 `System.IO.Path.InternalGetTempFileName` 认栈）：
  `CommandLineArguments.WriteToTempFile → BuildAsArgs → AotNativeLinkAndroid.Link`，即 Burst 的 Android AOT **链接阶段**建临时响应文件失败。
- 伴随症状：`Library/Bee/artifacts/Android/AsyncPluginsFromLinker` 是**空目录**（正常应为 `arm64-v8a/lib_burst_generated.so`）。说明该 Bee 节点上次被中断，留下半成品状态，之后每次构建都在同一节点复现失败。

- **有效修复：删除整个 `Library/Bee`（2.4G）强制完整重建**。清完首次重建仍失败一次（当时另有一份被排队的构建在跑，疑似并发），之后连续 3 次构建全部成功。
