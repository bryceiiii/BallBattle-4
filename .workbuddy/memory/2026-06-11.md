# BallBattle-4 联机大厅 UI 代码生成 — 概览

## 完成内容

将 `LobbyUIController.cs` 从"依赖Inspector拖拽"彻底改写为**完全由代码自动生成UI**的版本。

### 关键改动

| 旧版本 | 新版本 |
|--------|--------|
| 所有UI引用在Inspector拖拽 | Start() 中自动创建所有UI元素 |
| 手动创建Canvas/Panel/InputField等 | 工厂方法自动创建：MakePanel/MakeText/MakeInputField/MakeDropdown/MakeButton |
| 无法运行时独立运行 | 挂到任意GameObject即可自动生成完整的联机大厅 |

### 自动生成的UI结构

```
LobbyCanvas (Screen Space Overlay)
└── LobbyPanel (半透明深色面板, 480×440)
    ├── 标题 "BallBattle-4"
    ├── 副标题 "多人联机大厅"
    ├── 玩家名 输入框
    ├── 连接模式 下拉菜单 (本机/局域网/云端)
    ├── LAN设置组 (IP输入 + 端口输入, 选局域网时显示)
    ├── 状态文字 (连接状态反馈)
    ├── 连接按钮 (蓝色)
    ├── 进入游戏按钮 (绿色)
    └── 本机IP提示
```

### 设计特点

- 深色主题：半透明深蓝背景 + 浅色文字
- 蓝色主按钮、绿色进入按钮，视觉层次清晰
- 选局域网模式时面板自动展开显示IP/端口输入
- 连接成功/失败有颜色反馈（绿色/红色）
- 支持1920×1080参考分辨率，CanvasScaler自动适配

### 使用方式

1. 在场景中创建一个空GameObject
2. 挂上 `LobbyUIController.cs` 脚本
3. 运行即可看到联机大厅

## NetworkMonitor 手机端不运行修复

### 根因
Android IL2CPP 下，`SpacetimeDBNetworkManager.OnConnected` 事件从后台线程触发，
IL2CPP 的 managed/native 边界会吞掉事件回调，导致 `NetworkMonitor.OnGameConnected()` 收不到。
（SpacetimeDBNetworkManager.cs 第127行注释早已记录了此问题，LobbyUIController 已改用轮询）

### 修复（NetworkMonitor.cs）
- `Update()` 中添加连接状态轮询：`SpacetimeDBNetworkManager.Instance.IsConnected`
- 用 `_connectionChecked` 标记防重复触发
- `OnGameDisconnected` 中重置 `_connectionChecked`，支持断线重连后重新检测
- 原有的事件订阅保留（PC 端正常工作），轮询作为 Android 兜底
