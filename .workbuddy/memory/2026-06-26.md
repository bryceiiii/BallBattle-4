### Cloudflare Tunnel 公网联机方案实施

**背景**：用户需要让朋友通过公网连接本地 SpacetimeDB 游戏服务器。

**尝试过程**：
1. 安装并注册 `cloudflared`，创建 named tunnel `ballbattle`，绑定免费域名 `ballbattlezc.qzz.io`（DigitalPlat）
2. 诊断发现 `.qzz.io` 免费域名在国内三大运营商 DNS 不可达 + Cloudflare 边缘 IP 被 GFW 阻断 → named tunnel 不可用
3. Quick Tunnel（`trycloudflare.com`）经测试可正常穿透 ✅
4. 写了一个全自动启动脚本 `start-tunnel.ps1`，集成 `tunnel_helper.py` 自动提取 URL

**最终成果**：
- `start-tunnel.ps1`：一键启动 SpacetimeDB + Cloudflare Quick Tunnel + URL 提取（全自动）
- `stop-tunnel.ps1`：一键停止所有服务
- `redirect.html`：Web 入口页（可选，部署 GitHub Pages 用）
- 玩家公网 IP：112.12.255.76（保留用于可能的端口映射方案）
- 联机部署指南已更新，新增方案三（Cloudflare Tunnel）

**限制**：
- Quick Tunnel URL 每次重启会变
- GitHub Gist 自动发布功能待用户生成带 gist 权限的新 Token
- 经 Cloudflare 美国节点中转，延迟 150-300ms

**文件变更**：
- 新增：`start-tunnel.ps1`, `stop-tunnel.ps1`, `redirect.html`
- 修改：`联机部署指南.md`
