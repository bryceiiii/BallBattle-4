## 修复瞬移/同队球抖动（根因双管齐下）
- **根因1（主因）**：`GameManager.SetupCrossPlayerCollisionIgnore` 原来只对不同玩家球 IgnoreCollision，同玩家球仍物理互撞。服务端移动中不分同队球 + 小球快大球慢 → 深重叠 → Unity depenetration 一次性推开 = 瞬移/抖动。改为**圆-圆一律 IgnoreCollision(true)**（吃球/合并判定全在服务端，客户端无需圆-圆物理）。
- **根因2**：`CircleController.FixedUpdate` 的 SmoothDamp 没传 maxSpeed（默认 Infinity），本地 smoothTime 0.05s，目标跳远时无限速追平=瞬移。加 `localPosMaxSpeed=30` / `remotePosMaxSpeed=35` 字段，SmoothDamp 传 maxSpeed 以真实球速滑行追平。
- 球速基准：`START_PLAYER_SPEED=14`，加速 buff ×1.8≈25，maxSpeed 取 30 留余量。
- 未做客户端预测（沿用 ponytail 约定：SmoothDamp + maxSpeed 足够平滑）。

## 同队球移动时也不重叠（服务端权威分离）
- 需求：玩家移动时，自己分裂出的球之间也不能重叠（深叠成一块）。
- 实现：`Lib.cs` MoveAllPlayer 里，在移动阶段之后、吞噬检测之前，新增「同队球防重叠分离」：遍历 `playerBalls`，对重叠(dist < ra+rb)的同队球沿连线**温和推开**（每 tick 只消除 `SEPARATION_FACTOR=0.5` 的重叠，按质量反比分配推挤量，小球被推开更多），推到相切后停止。
- 与合并的关系：分离只推到相切(dist≈ra+rb)，仍在合并判定的 +0.03 余量内，不影响贴合合并计时。
- 客户端保持圆-圆 IgnoreCollision（不做物理碰撞），靠服务端分离 + SmoothDamp(maxSpeed) 平滑呈现，不瞬移不抖动。
- 需 `spacetime publish` 重新部署。
