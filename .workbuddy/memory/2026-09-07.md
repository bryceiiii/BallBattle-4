## 修复瞬移/同队球抖动（根因双管齐下）
- **根因1（主因）**：`GameManager.SetupCrossPlayerCollisionIgnore` 原来只对不同玩家球 IgnoreCollision，同玩家球仍物理互撞。服务端移动中不分同队球 + 小球快大球慢 → 深重叠 → Unity depenetration 一次性推开 = 瞬移/抖动。改为**圆-圆一律 IgnoreCollision(true)**（吃球/合并判定全在服务端，客户端无需圆-圆物理）。
- **根因2**：`CircleController.FixedUpdate` 的 SmoothDamp 没传 maxSpeed（默认 Infinity），本地 smoothTime 0.05s，目标跳远时无限速追平=瞬移。加 `localPosMaxSpeed=30` / `remotePosMaxSpeed=35` 字段，SmoothDamp 传 maxSpeed 以真实球速滑行追平。
- 球速基准：`START_PLAYER_SPEED=14`，加速 buff ×1.8≈25，maxSpeed 取 30 留余量。
- 未做客户端预测（沿用 ponytail 约定：SmoothDamp + maxSpeed 足够平滑）。

## 同队球移动时也不重叠（服务端权威分离）
- 需求：玩家移动时，自己分裂出的球之间也不能重叠（深叠成一块）。
- 实现：`Lib.cs` MoveAllPlayer 里，在移动阶段之后、吞噬检测之前，新增「同队球防重叠分离」：遍历 `playerBalls`，对重叠(dist < ra+rb)的同队球沿连线**温和推开**（每 tick 只消除 `SEPARATION_FACTOR=0.5` 的重叠，按质量反比分配推挤量，小球被推开更多），推到相切后停止。
- 与合并的关系：分离只推到相切(dist≈ra+rb)，仍在合并判定的 +0.03 余量内，不影响贴合合并计时。
- 客户端保持圆-圆 IgnoreCollision（不做物理碰撞），靠服务端分离 + SmoothDamp(maxSpeed) 平滑呈现，不瞬移不抖动。
- 需 `spacetime publish` 重新部署。

## 射击手感（Game Feel）系统
- 新增纯客户端表现层，**绝不写服务端表、绝不等回包**，全部当帧立即生效。
- 新增文件：`GameFeel.cs`（单例，懒自动创建；集中管理顿帧/震动/闪光/后座/爆炸/飘字/音效池，全部参数 Inspector 可调）、`GameFeelParticle.cs`（自驱动粒子）、`FloatingText.cs`（世界空间飘字）。
- `CameraContoller`：新增 `Shake(intensity, duration)`；用 `_logicalPos` 分离逻辑位置与震动偏移，避免震动被 SmoothDamp 平滑"吃掉"。
- `CircleController`：新增 `ApplyRecoil(dir, dist)` + `FlashColor(color, dur)`；`_recoilOffset` 指数回弹、在 FixedUpdate 的 MovePosition 叠加（不动 targetPos）；缓存 `_sr`/`_baseColor`，闪色后恢复。
- `GameManager`：新增 `GetLocalMainBallController()` 公共静态方法。
- 开火路径：`PlayerInputController.HandleShootInput` 和 `MobileInputController.Shoot` 都调 `GameFeel.Instance?.OnFire(dir)`；分裂调 `OnSplit()`。
- 命中路径：`BulletController.OnTriggerEnter2D` 调 `GameFeel.Instance?.OnHit(pos, targetCtrl, bulletDir)`（bulletDir 取 `_posVelocity` 兜底 `_targetPos-pos`）。
- 空枪：`OnFire` 内按 0.25s（服务端 BULLET_COOLDOWN_SEC 镜像）判断，冷却中播放轻空枪音+小闪光，不播完整开火反馈。
- HitStop：协程 + `WaitForSecondsRealtime`，记录原始 timeScale，OnDestroy 兜底恢复；连中时 StopCoroutine 重启不累积。
- 音效：程序生成占位音（fire/hit/empty/split），AudioSource 池复用；**注意 PlayOneShot 不响应 pitch**，改用 `src.clip + src.pitch + src.Play()` 实现随机音高。
- 子弹速度感（可选）：`BulletController` 加 `enableVelocityStretch`（沿速度拉伸+旋转）+ `enableTrail`（TrailRenderer），默认关闭。
- 飘字（可选）：`GameFeel.SpawnDamageNumber(pos, dmg, blocked)` API + 池就绪；但伤害/格挡值服务端未同步到客户端，暂未自动接线。
