# 2026-09-07 工作日志

## 修复射击方向不一致 + 瞄准手感 + 双输入抢占

### 1. 射击方向协议改为归一化方向向量
- `Lib.cs` ShootBullet：语义从"世界目标点"改为"归一化方向"。开头 normalize 一次，所有球共用同一方向（平行弹道）。**reducer 签名 `(float,float,int)` 不变，schema 未变，无需重新 generate autogen**，但需 `spacetime publish` 重新部署。
- `PlayerInputController.HandleShootInput`：改为发送 `normalize(鼠标世界点 - 主球位置)` 方向。
- `MobileInputController.Shoot`：改为发送 `AimDirection`（归一化），不再发 `ballPos + dir*10` 假目标点。

### 2. 瞄准摇杆手感
- `VirtualJoystick` 新增 `useRawDirection` 开关：true 时 `Direction = RawDirection`（不平滑），仅视觉手柄用 SmoothDamp。
- `MobileInputController.HandleMobileInput`：改用 `aimJoystick.RawDirection` 计算 AimDirection，未收敛小向量不 normalize。
- `aimShootThreshold` 默认 0.3 → 0.18。
- 场景 MainScene.unity：ShootJoystickBg 的 VirtualJoystick 设 `useRawDirection:1`、`powerCurve:1.2`、`directionSmoothTime:0.01`。

### 3. PC/移动双输入二选一
- `PlatformInputManager`：IsMobileMode 判断提前到 Awake；缓存场景烘焙的 `_bakedMobileInput`；PC 分支禁用烘焙 MobileInputController + ShowMobileUI(false) + 隐藏 MobileTouchCanvas；移动分支优先复用烘焙输入并禁用 PlayerInputController。
- `MobileInputController.Start`：感知 PlatformInputManager，PC 下自禁用（enabled=false）+ 隐藏 UI。
- `AimIndicator.Update`：改用 `PlatformInputManager.IsMobileMode` 判断分支（不再用 forceMobileMode），PC 下箭头跟鼠标。

## 关键约定
- ShootBullet 客户端一律发「归一化方向」，服务器所有球平行发射（不再按 DB 第一个球算方向）。
- 移动端瞄准用 `RawDirection`（跟手），视觉手柄才用平滑。
