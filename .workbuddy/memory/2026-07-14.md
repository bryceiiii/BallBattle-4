# 2026-07-14

## 皮肤选择系统

为球球大作战(BallBattle-4)添加了完整的皮肤选择功能：

### 新增文件
- `Assets/Scripts/SkinManager.cs` — 皮肤管理器单例，存储可选皮肤列表和当前选中状态
- `Assets/Scripts/SkinSelectionUIController.cs` — 皮肤选择面板UI，连接成功后自动显示，程序化构建皮肤网格

### 修改文件
- `Assets/Scripts/LobbyUIController.cs` — 连接成功后跳转皮肤选择面板（而非直接进入游戏）；新增 `OnSkinConfirmed()` 回调
- `Assets/Scripts/CircleController.cs` — `ApplyLocalPlayerVisual()` 方法中增加从 SkinManager 读取皮肤并应用到 SpriteRenderer 的逻辑

### 流程
连接成功 → 显示皮肤选择面板 → 玩家选择皮肤 → 点击确认 → 进入游戏（本地玩家球自动应用选中皮肤）
