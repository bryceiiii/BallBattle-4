## HP 条受击反馈（抖动 + 闪白，方案 B）
- 需求：玩家头顶血条在掉血时做"抖动 + 闪白"的打击反馈（借鉴抖音"血条制作 无插件"，方案 B）。
- 改动文件：`CircleController.cs`，纯客户端表现，不碰服务端。
- 实现要点：
  1. 新增字段（Inspector 可调）：`hpFlashDuration=0.12`、`hpShakeDuration=0.2`、`hpShakeIntensity=0.02`；私有 `_hpFlashTimer/_hpShakeTimer/_hpWasFlashing/_lastHp`。
  2. `SetHp()` 顶部加掉血检测：`currentHp < _lastHp - 0.001f` → 触发闪白+抖动（`_lastHp` 记录上一次血量，涨血/满血不触发）。
  3. 抽 `ApplyHpFillColor(ratio)`：三档色绿(>60%)/黄(30-60%)/红(<30%)，闪白期间由 Update 盖白色、结束后恢复。
  4. `Update()` 里闪白/抖动计时递减；`_hpWasFlashing` 期间把 `hpFillImage.color` 盖白，计时结束恢复三档色。
  5. 血条位置跟随段（约 465 行）叠加 `Random.Range(-amp,amp)` 抖动，幅度随剩余时间线性衰减到 0。
- 关键约定：闪白用 `Color.white` 盖 `hpFillImage.color`，与球体闪色 `_flashColor/_baseColor`（SpriteRenderer）互不干扰，两套独立。
- 血条结构回顾：`HpCanvas`(子物体) → `HpBarFill`(填充条，用 sizeDelta.x 控制宽度) → `HpBarBg`(背景框)。`hpCanvasRect` 是 Canvas 的 RectTransform。
